# Backlog

- **Suppression du système de saison — ⚠️ AUDITÉ, NON FAIT (2026-08-15, question porteur)** : le porteur demandait si retirer le système de saison casserait quelque chose. **Réponse : oui — suppression ÉCARTÉE.** Preuves : `season_enrollments` est la colonne vertébrale d'inscription partagée avec les campagnes B2B (cohorte, `rejoindre.$campaignId`), l'assignation mentor (`assignMentorToChildAdmin` y résout la campagne d'un enfant), la couverture/accès (`getChildAccessStatus`), l'accompagnement (`resolveChildAccompaniment`), les abonnements (`subscriptions.functions` L383) ; et `sponsorship_tokens.season_id` est une FK **NOT NULL** vers `seasons` — chaque lot de codes B2B/parrainage/paiement en ligne insère `season_id` via `getActiveSeason` (campagnes, parrainage, payment-fulfillment). Purger exigerait d'abord de découpler : rendre `sponsorship_tokens.season_id` nullable + vider les inserts, puis retirer le badge « Saison »/Certificat (portfolio + page Défis) — à ne faire que si le porteur le re-demande explicitement.
