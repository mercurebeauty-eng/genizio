- **Génération IA plus fine** : Ajuster les prompts pour mieux contextualiser les défis à l'Afrique francophone (matériaux, environnements spécifiques).
- **Application mobile dédiée** : Transformer cette PWA (TanStack Start) en application mobile native ou Capacitor pour simplifier la prise de photo.
- **Paramétrage des récompenses** : Permettre au parent de configurer des cadeaux physiques ou monétaires débloqués en fonction des points de talents accumulés.

- **Refonte UI globale** : L'utilisateur juge l'UI actuelle "AI-generated" / générique au-delà de la seule question de la police — discussion explicitement mise en pause le temps de traiter Naya en premier ("avant de parler de l'ui globale je vais parler de l'IA interne"). **Mise à jour 2026-07-20 : le scoping Naya est fait** ([[genizio-naya-systeme-comprehension]], décision #27) — la conversation refonte UI peut être reprise quand l'utilisateur le souhaite. Une tentative d'import via un wireframe Claude Design (`Génizio Wireframes.dc.html`) a échoué faute d'accès (voir [[genizio-etat-code]]) — reste à trouver un moyen d'en récupérer le contenu (export/partage claudeusercontent.com, ou fichier local).
- **Audit ligne à ligne post-rename** : `genizio_etat_code.md` "Ce qui est en place et fonctionne" date du 2026-07-15 et n'a pas été re-vérifié fonctionnellement depuis (seuls les textes/branding ont changé). Faire un passage de vérification directe dans le navigateur des flux clés (génération de défi, validation de preuve) avant la prochaine session de fonctionnalités.
- **Vue Postgres dédiée pour le Mur public** : la policy RLS publique sur `child_profiles` (cf. - **Audit RLS complet du schéma — fait le 2026-07-17** (cf. Voir [[genizio-decisions]] #76.
- **✅ Photos iOS HEIC — IMPLÉMENTÉ (2026-08-15, décision #77)** : les Live Photos iPhone (HEIC) échouaient à l'envoi (« Image illisible. » — le pipeline `<img>`/canvas ne décode pas le HEIC), obligeant à une capture d'écran. **Corrigé** : conversion HEIC→JPEG côté client (heic2any, WASM en import dynamique, partagé /quest + OutcomeChat + mentor) avec repli envoi brut → filet serveur (conversion WASM `libheif-js` + mozjpeg `@jsquash/jpeg`, octets embarqués — sharp impossible sur le runtime Cloudflare Workers). Au passage, la compression est durcie sur Safari : `canvas.toBlob('image/webp')` y retombait silencieusement sur un PNG de plusieurs Mo (le repli ne vérifiait pas le type réel du blob) — ré-encodage JPEG explicite. Voir [[genizio-decisions]] #77.
- **✅ Confiance Mentor — IMPLÉMENTÉ (2026-08-15, décision #79, branche `feat/confiance-mentor`)** : récompense/punition des mentors automatisées et validées par le parent. **Livré** : statut `confirmed` (déclaré → confirmé parent → approuvé admin → payé) + `confirmMentorSession` ; score/payout = séances CONFIRMÉES uniquement ; points `mentor_points` (séance +1, défi +2, note 5/5 +1, paliers Bronze/30→+5 %/Or 60→+10 %) ; statut automatique 2 sens sur fenêtre glissante 30 j (warning < 40, suspended < 25, jamais banned) ; palier confiance ≥ 75 → payout 75 % (3 750 F) ; push Web Push VAPID (SW injectManifest, `push_subscriptions`, `sendPushToUser`) + email Brevo idempotent orchestrés par `notifyUser` (in-app + push + email sur tous les événements mentor) ; UI hub parent « Séances à valider », panneau notifications mentor, badges confiance/points. Voir [[genizio-decisions]] #79.
- **Contester une séance** (décision #79, différé) : le parent ne peut aujourd'hui que CONFIRMER une séance déclarée (ou la laisser en attente). Un rejet explicite (séance non réalisée / injustifiée) est le complément naturel de la validation — il annulerait la séance, débloquerait la séance de pack, et pénaliserait fortement le score (à définir : poids du motif, garde anti-abus). Le feedback 1-5 couvre provisoirement le mécontentement.
- **Cadeau boutique au palier 60 pts** (décision #79, différé) : le palier Or (+10 % payout) est livré, mais le « cadeau » (bon d'achat/kit de la boutique, table `orders` existante) n'est pas intégré — nécessite de relier `mentor_points` au catalogue produits et au flux de commande. Hors scope du chantier confiance.
- **Panneau in-app admin des notifications** (décision #79, différé) : les admins reçoivent push + email sur les bascules de statut, mais aucun écran admin ne liste `app_notifications` (les deux panneaux existants sont côté parent et mentor). La page « Gestion des Mentors » montre déjà le statut — un journal des bascules serait un plus.
